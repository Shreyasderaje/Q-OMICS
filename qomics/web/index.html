Early-stage detection from joint transcriptome, genome and proteome measurements.

A fidelity quantum kernel supplies the geometry; a cross-omic attention stack reads it. Biomarker attribution is taken directly from the attention rollout rather than from a post-hoc surrogate.

Method

Six stages, one token per molecular feature

Reduction is performed per layer so that no modality is compressed by a shared projection. The quantum stage produces a kernel matrix over the reduced representation; the token sequence is the reduced representation itself.
